# Code of Conduct

## Pledge

We want Relay to be a project people can file issues against and send patches to without being harassed. Participants keep criticism on the code and the behavior, and leave personal attacks out.

## Expected behavior

- Assume good faith, and ask when a provider's documentation is unclear.
- Say what you actually tested.
- Do not post other people's credentials, private chats, or contact details.
- Do not open a pull request that pretends an integration works.

## Unacceptable behavior

- Insults, slurs, or sexual attention aimed at another person.
- Publishing private information without permission.
- Sustained disruption of issues or reviews.

## Enforcement

Project maintainers can edit or reject issues, comments, and pull requests that break this file. Report a conduct problem through https://github.com/manjeetsingh-satveer/Relay/security/advisories/new, not in a public issue that names a private individual.

## Attribution

This is a short project-specific policy. It is not the Contributor Covenant. The ideas of a pledge, standards, and maintainer enforcement are in wide use; the wording here is Relay's.
